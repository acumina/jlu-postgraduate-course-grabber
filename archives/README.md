# archives —— 课程档案存档目录

把你从面板「档案」页导出的 `kx-courses-*.json` 放进这个文件夹，插件就能**直接在面板里读取**它们
（不需要每次弹文件选择框）。

## 用法

1. 把导出的 JSON 拷进本目录，例如：
   ```
   archives/kx-courses-20260917-1540.json
   ```
2. 在本项目目录执行一次（生成索引，让插件知道有哪些文件）：
   ```
   node tools/make-archive-index.mjs
   ```
3. 到 `chrome://extensions` 点一次 🔄 重新加载扩展
4. 面板 → **档案** 页顶部会出现「项目 archives/ 目录里的档案」列表，点「读取」即可

> 为什么需要索引：浏览器扩展**不允许枚举自己目录里的文件**（安全限制），
> 所以得有个 `index.json` 明确列出文件名。第 2 步的工具就是干这个的。

## 长期用法（跨年）

- **今年**：档案页 → 导出为文件 → 把文件拷进这里 → 跑一次索引工具 → 重载 → 以后随时可读
- **明年开课前**：档案页 → 从列表里「读取」今年的档案 → 浏览/搜索 → 勾选目标 → 加入监控
- **明年选课开了**：插件会自动按课程名把监控列表里那些"查不到ID"的目标**模糊匹配回新ID**
  （置信度高的自动改；同名多班存疑的会提示你在面板上选）

## 也可以临时读任意文件夹

面板档案页还有「选择文件夹…」按钮 —— 选任意目录，它会列出里面的 `.json` 让你点着读，
不需要索引、不需要重载。适合临时看一下别人给的档案。
