Chrome MV3 选课插件，**原生 JS 零构建**。这一版把「从零开始」也变成全自动。

## 适用系统

| | |
| --- | --- |
| 学校 / 系统 | **吉林大学研究生选课系统** |
| 首页（登录入口） | `https://yjsxk.jlu.edu.cn/yjsxkapp/sys/xsxkapp/index.html` |
| **选课页**（引擎真正跑的地方） | `https://yjsxk.jlu.edu.cn/yjsxkapp/sys/xsxkapp/course.html` |
| 生效范围 | **只在 `yjsxk.jlu.edu.cn` 上出现面板**，其它网站完全不动 |

## 怎么用（3 步，只有第 2 步需要你动手）

1. **装扩展**：解压这个 ZIP → `chrome://extensions` → 打开「开发者模式」→
   「加载已解压的扩展程序」→ 选解压出来的文件夹
   （`manifest.json` 就在根目录。不需要 Node、不需要导入配置）
2. **打开首页登录**（`.../xsxkapp/index.html`），像平时一样输账号密码 + 图形验证码
   —— **这是唯一的手动步骤**（登录无法自动化，本插件不含任何绕过验证码的功能）
3. **点进选课页**（`course.html`）→ **之后全自动**：
   自动取得一次性参数 `csrfToken`（必要时用页面内点击取，约 70ms）→
   拉课程列表 → 匹配目标 → 余量监控 → 命中就提交 → 用「已选课程」列表核对是否选上

> 抢课期间**让选课页保持可见**（Chrome 会把后台标签页的定时器压到每分钟 1 次）。

## 这一版新增：从零开始也全自动

- **不再需要"加入白名单"这一步**：面板发现当前站点还没配置时，会**自动应用内置预设**
  （生效站点、提交/查询接口、判定规则一次配好），你不需要手动配白名单、也不用点「载入内置预设」
- **登录页就会弹出"挑去年课表"**：如果这是一个全新环境（没有任何目标）而插件手上有课表档案，
  它会**自动展开面板并切到「档案」页**，让你直接在**登录页**从去年的课表里勾选要抢的课 →
  「加入备选清单」→ 明年的教学班 ID 自动匹配

## 明年 / 换电脑的完整流程

```
装扩展（解压 → 加载已解压的扩展程序）
   ↓ 自动：读取项目配置（或内置预设）→ 站点/接口自动配好
打开首页登录（输验证码 ← 唯一手动步骤）
   ↓ 自动：点进选课页 → 拉全量课表 → 按「课程名+教师+校区」模糊匹配今年的教学班
   ↓ 自动：匹配到就加入监控 → 取 token → 模拟发包抢课
```

匹配用**最大兜底**：相似度不够也采用最像的那个 —— 多抢一门只是退一次课（可逆），
匹配不到就整轮错过（不可逆）。关掉：`engine.autoResolveFallback = false`。

**备选清单怎么来的**：今年在「档案」页勾课 → 「加入备选清单」→
「复制为配置片段」→ 粘进 `kx-config-吉大研究生选课.json` 的 `"wishlist"` 字段 → 保存。

## 会自动开始吗？—— 会

| 场景 | 行为 |
| --- | --- |
| 首次装好扩展 | 默认就是「运行中」，**一进选课页就自动开抢**，不用点「启动」 |
| 刷新页面 / 重开浏览器 | 自动恢复继续抢 |
| 掉线后你重新登录（含验证码） | 自动继续，不用手点 |
| **你手动点过「停」**（或撞上验证码自动停机） | **不会**自己恢复（主动停机是粘性的：你收手时插件不该背着你继续发请求） |
| 停在首页 `index.html` | 只有面板，引擎不跑；点进选课页就接着跑 |

## 安全与合规（请先读）

- 插件跑在**你自己的浏览器**里，复用你本来就会发出的请求；**不包含任何绕过登录验证（如验证码识别）的功能**
- 这类行为**很可能与学校的选课系统使用条款、教务规定相冲突**，也可能触发风控 —— 风险与合规责任由使用者自负
- 抓包与日志**只存在本地**（`logs/` 已被 `.gitignore` 排除）；推送/导出时自动脱敏（密码/验证码/学号/Cookie → `***`）
- 本仓库**不含任何个人信息**；附带的 `archives/` 是学校**公开课表快照**

## 已知限制

- 会话是短命的（实测约 9～14 分钟）：掉线后需要你**手动输验证码**重新登录，之后自动继续
- Chrome 限制后台标签页定时器 —— **抢课期间请让选课页保持可见**
- 提交判定的文案来自抓包，各校/各系统版本可能不同：设置页可改 `submit.rules`
