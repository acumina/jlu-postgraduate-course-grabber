Chrome MV3 选课插件，**原生 JS 零构建**。这一版修掉 3 个真 bug —— 都是"在新电脑上从零开始"时才会踩到的。

## 适用系统

| | |
| --- | --- |
| 学校 / 系统 | **吉林大学研究生选课系统** |
| 首页（登录入口） | `https://yjsxk.jlu.edu.cn/yjsxkapp/sys/xsxkapp/index.html` |
| **选课页**（引擎真正跑的地方） | `https://yjsxk.jlu.edu.cn/yjsxkapp/sys/xsxkapp/course.html` |
| 生效范围 | **只在 `yjsxk.jlu.edu.cn` 上出现面板**，其它网站完全不动 |

## 怎么用（3 步，只有第 2 步需要你动手）

1. **装扩展**：解压这个 ZIP → `chrome://extensions` → 打开「开发者模式」→
   「加载已解压的扩展程序」→ 选解压出来的文件夹
2. **打开首页登录**（含图形验证码）—— **唯一的手动步骤**
3. **点进选课页** → 之后全自动：取 `csrfToken` → 拉课表 → 匹配目标 → 余量监控 → 命中就提交

> 抢课期间**让选课页保持可见**（Chrome 会把后台标签页的定时器压到每分钟 1 次）。

## 这一版修了什么（都是实测踩到的）

### ① 新电脑上"没能弹出历史课表"

`loadArchive()` 只读浏览器存储，而**新电脑上那个键是空的** —— 项目里带的课表快照
（`archives/*.json`）从来没被自动读过。于是「档案」页空着、挑不了课，
"从零开始"引导的条件（要有档案）也不成立，**永远不弹**。

**修**：启动时自动读取项目里**档案时间最新**的那一份快照（已有档案时绝不覆盖）。

### ② 加了备选清单不立刻生效

以前只存清单，要等下次页面加载才变成监控目标 —— 感觉像"加了没反应"。
**修**：加完立刻变成目标，并立刻尝试按课程名解析一次。

### ③ 最严重的：`halt()` 里用了**根本不存在的变量**

```js
function halt(reason, urgent) {
  ...
  if (!loginRelated) setWantRunning(false);   // ← loginRelated 从未声明
```

严格模式下**每次停机都抛 ReferenceError** → 后面的 `saveRuntime()`、面板刷新、
以及**"登录后自动继续"的判断**全都没执行 → 表现就是**"登录了也不自动开始抢课"**。

**修**：停机改成显式选项 `{ urgent, sticky, kind }`，整段包 `try/catch`，
并把 6 个调用点的语义逐个写清：

| 停机原因 | 是否撤回"想跑"的意图 |
| --- | --- |
| 触发验证码 | **撤回**（必须你人工处理后再点启动） |
| 登录失效 | 不撤回（登录后自动继续） |
| **未到选课时间** | **不撤回** —— 明年场景：窗口一开就自动开始（以前是撤回的，会一直不动） |

## 另外：新增未声明变量的自动检查

零依赖项目没有 eslint，`node --check` 只查语法、查不出"用了但从未声明的变量"。
新增 `tools/lint-undefined.mjs`（高精度 + 基线白名单），已确认**能抓到当初那个 `loginRelated`**，
并接进 `npm test`。

## 明年 / 换电脑的完整流程（现在真的只剩登录是手动）

```
装扩展（解压 → 加载已解压的扩展程序）    ← 不用配白名单、不用导入配置
   ↓ 自动：应用项目配置/内置预设 → 自动读取项目里的课表快照
打开首页登录（输验证码）                 ← 唯一手动步骤
   ↓ 自动：全新环境时展开面板并切到「档案」页，让你从**去年的课表**里挑课
   ↓ 自动：点进选课页 → 拉全量课表 → 按「课程名+教师+校区」模糊匹配（最大兜底）
   ↓ 自动：加入监控 → 取 token → 模拟发包抢课
```

## 安全与合规（请先读）

- 插件跑在**你自己的浏览器**里，复用你本来就会发出的请求；**不包含任何绕过登录验证（如验证码识别）的功能**
- 这类行为**很可能与学校的选课系统使用条款、教务规定相冲突**，也可能触发风控 —— 风险与合规责任由使用者自负
- 抓包与日志**只存在本地**（`logs/` 已被 `.gitignore` 排除）；推送/导出时自动脱敏
- 本仓库**不含任何个人信息**；附带的 `archives/` 是学校**公开课表快照**
