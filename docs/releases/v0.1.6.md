Chrome MV3 选课插件，**原生 JS 零构建**。这一版按设计要求改了匹配策略：
**一门课匹配到多少个教学班，就抢多少个。**

## 适用系统

| | |
| --- | --- |
| 学校 / 系统 | **吉林大学研究生选课系统** |
| 首页（登录入口） | `https://yjsxk.jlu.edu.cn/yjsxkapp/sys/xsxkapp/index.html` |
| **选课页**（引擎真正跑的地方） | `https://yjsxk.jlu.edu.cn/yjsxkapp/sys/xsxkapp/course.html` |
| 生效范围 | **只在 `yjsxk.jlu.edu.cn` 上出现面板**，其它网站完全不动 |

## 这一版改了什么

### 「全部模糊命中都要」

> 最大兜底选课要选择全部模糊命中的课程，不能选一门抢就不抢其他的了

以前按课程名匹配时**只挑相似度最高的那一个**教学班。同名教学班常有十几个
（羽毛球×12、篮球×9），只挑一个等于把机会缩小到 1/12。

**现在**：匹配到的教学班**全部加入监控** —— 「羽毛球」有 12 个班就建 12 个目标，
哪个先有名额就抢哪个。抢到之后**其余仍继续抢**（`autoStopSameName=false`）：
多抢一门只是去学校页面退一次课（可逆），漏掉却是整轮错过（不可逆）。

顺手修掉一个真实缺口：`matchCoursesByName` 默认**只返回前 5 个候选**
（面板里给人挑够用了）—— 解析器现在会显式放大到 `expandMax`（默认 30），
否则羽毛球×12 永远只能匹配到 5 个。

相关配置：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `engine.expandAllMatches` | `true` | 全部命中都要（改成 `false` 就回到"只挑最像的一个"） |
| `engine.expandMax` | `30` | 单门课最多展开多少个教学班（防止某课几百个班刷爆列表） |
| `engine.autoStopSameName` | `false` | 抢到一门后**不**停掉同名其它班 |
| `engine.keepPollingAfterSuccess` | `true` | 判定成功后继续轮询/提交 |

同名组成员在「目标」页有明确标注（`同名第N个班`）与说明，不会以为是重复项。

## 怎么用（3 步，只有第 2 步需要你动手）

1. **装扩展**：解压 ZIP → `chrome://extensions` → 打开「开发者模式」→
   「加载已解压的扩展程序」→ 选解压出来的文件夹
2. **打开首页登录**（含图形验证码）—— **唯一的手动步骤**
3. **点进选课页** → 之后全自动：取 `csrfToken` → 拉课表 → 按课程名匹配（全部命中都要）
   → 余量监控 → 命中就提交

> 抢课期间**让选课页保持可见**（Chrome 会把后台标签页的定时器压到每分钟 1 次）。

## 安全与合规（请先读）

- 插件跑在**你自己的浏览器**里，复用你本来就会发出的请求；**不包含任何绕过登录验证（如验证码识别）的功能**
- 这类行为**很可能与学校的选课系统使用条款、教务规定相冲突**，也可能触发风控 —— 风险与合规责任由使用者自负
- 抓包与日志**只存在本地**（`logs/` 已被 `.gitignore` 排除）；推送/导出时自动脱敏
- 本仓库**不含任何个人信息**；附带的 `archives/` 是学校**公开课表快照**
