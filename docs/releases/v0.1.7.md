Chrome MV3 选课插件，**原生 JS 零构建**。这一版把课表档案**补齐到 148 门**。

## 补了什么

档案里原本缺 **研究生心理成长（A0321000003）** 这一门 —— 原因是**我（作者）自己已经把它选上了**：
学校系统在你选上之后就把该课从「**可选课程**」列表移走，而档案正是"可选课程"的快照。

抓包时间戳可以证明：

```
该课出现在 loadGxkCourseInfo.do（可选课程）: 38 次，最晚 15:25:51
15:28:31  选课成功
15:49:40  建立档案快照 → 此时它已不在可选列表里 → 所以缺了它
（它一直出现在 loadStdCourseInfo.do「已选课程」里，到 16:16:49 都能查到）
```

**但档案是给别人用的** —— 对别人来说它就是一门可选课，所以这一版按抓包里的原始记录
把它补回了档案：

| 字段 | 值 |
| --- | --- |
| 课程名 / 教学班 | 研究生心理成长 / 研究生心理成长01 |
| 课程号 | A0321000003 |
| 教学班ID | `20261-111-A0321000003-1788793882416` |
| 教师 | 张琳 |
| 校区 | 任意校区 |
| 上课时间 | 4-13周（线上慕课）（取自学校备注字段：智慧树平台） |
| 容量 / 已选 | 1000 / 1000 |

档案现在 **148 门**，并记录了这次补录的来源（`backfilled` 字段），便于以后核对。

## 顺便说明「档案的范围」

- 档案 = 学校「**可选课程**」列表的快照 → **已经选上的课不会出现在里面**（学校系统行为，不是 bug）
- 想确认某门课选上没有 → 看面板「目标」页的**已选课程**区块（服务器权威数据）
- 想自己刷新档案 → 面板「档案」页 → 「刷新档案（全量查询）」

## 怎么用（3 步，只有第 2 步需要你动手）

1. **装扩展**：解压 ZIP → `chrome://extensions` → 打开「开发者模式」→
   「加载已解压的扩展程序」→ 选解压出来的文件夹
2. **打开首页登录**（含图形验证码）—— **唯一的手动步骤**
3. **点进选课页** → 之后全自动：取 `csrfToken` → 拉课表 → 按课程名匹配（**全部命中都要**）
   → 余量监控 → 命中就提交

## 安全与合规（请先读）

- 插件跑在**你自己的浏览器**里，复用你本来就会发出的请求；**不包含任何绕过登录验证（如验证码识别）的功能**
- 这类行为**很可能与学校的选课系统使用条款、教务规定相冲突**，也可能触发风控 —— 风险与合规责任由使用者自负
- 抓包与日志**只存在本地**（`logs/` 已被 `.gitignore` 排除）；推送/导出时自动脱敏
- 本仓库**不含任何个人信息**；附带的 `archives/` 是学校**公开课表快照**
